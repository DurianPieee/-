# 聊城大学竞赛渠道查询网站

面向聊城大学物理科学与信息工程学院（集成电路学院）学生的竞赛信息查询网站。

## 启动

需要 Python 3.9 或更新版本。进入本目录后运行：

```bash
python server.py
```

在浏览器打开 `http://127.0.0.1:8000`。若使用其他端口，可运行 `python server.py --port 8080`。

## 内容与更新

- 竞赛详情：根据所附学校竞赛分类表收录 192 项，提供级别、学科分类和逐项跳转入口。已核对并修正集成电路、嵌入式芯片、光电设计、物理实验四项的目录网址。
- 最新消息：启动时及此后每 6 小时，从学院官网“学生工作—学科竞赛”栏目读取最近 15 条；官网暂时无法访问时保留内置的最近一次数据。
- 校方政策：包含学院官网公开的 8 份培养方案、所附竞赛管理办法和标注为历史版本的 2024 年竞赛目录。
- 新生手册：尚未取得可核实的官方新版文件，因此展示学校官网入口，未填入猜测内容。
- 备赛资料与时间：只展示已核实的赛事官网资料链接。未查到官方公开赛题、作品或当届参赛时间的赛事会明确标注，并提供官网入口。

直接打开 `index.html` 也能浏览内置数据；要让最新消息持续同步，需要运行 `server.py` 并保持服务在线。正式发布时建议将 Python 服务放在持续运行的主机上，并通过 HTTPS 反向代理提供访问。

本网站是信息索引。报名时间、赛题、获奖认定和政策执行以学校及赛事主办方正式通知为准。
